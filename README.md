## Travail collectif

Chaque groupe code sa routine dans Basthon et la teste avec la version commune. Il enregistre ensuite son notebook dans OneDrive. Le professeur valide et publie les contributions sur GitHub : tous les groupes rouvrent le lien pour charger cette nouvelle version. Les modifications dans Basthon ne sont pas enregistrées automatiquement sur GitHub.
