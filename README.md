## Enregistrer et faire profiter les autres de sa routine

1. Télécharger le notebook et le rapport produits dans Basthon.
2. Les déposer dans le dossier OneDrive du groupe.
3. Après validation, le professeur publie la routine dans la version commune.
4. Les autres groupes ouvrent à nouveau le lien ou actualisent le module et relancent le calcul.

Le fichier classe_commune.py contient les douze routines de flux et le moteur, plus l’enveloppe Monte-Carlo. Les références professeur sont signalées ; les contributions validées portent leur statut. La version commune est affichée dans chaque rapport.

Le travail local ne se synchronise pas automatiquement avec GitHub. Les résultats personnels restent sur OneDrive jusqu’à sélection par le professeur. Le dépôt public contient des exemples et les résultats pédagogiques retenus, sans données personnelles.

## Traitement du temps

Le raccordement des routines des groupes utilise le moteur annuel. Le notebook collectif géologique est une réduction distincte pour les temps longs : il ne branche pas automatiquement ces routines. Les interfaces et limites sont expliquées dans les fiches des cahiers.
