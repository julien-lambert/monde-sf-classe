# Coder dans le navigateur

1. Dans OneDrive, télécharger G00_prise_en_main.ipynb, puis le notebook de votre groupe. Un aperçu OneDrive n'exécute pas les cellules.
2. Ouvrir https://notebook.basthon.fr. Utiliser le bouton d'ouverture/import d'un fichier et choisir le .ipynb téléchargé. Basthon permet d'importer les notebooks depuis l'ordinateur : https://basthon.fr/blog/2020/10/22/charger-un-fichier-de-donnees/.
3. Exécuter les cellules de haut en bas avec Maj + Entrée. Les zones « À VOUS » contiennent votre travail. Le message « À compléter » est normal avant d'écrire la routine. Une assertion échouée après modification est un résultat à analyser.
4. Télécharger/enregistrer régulièrement le notebook .ipynb, puis déposer cette copie dans le dossier OneDrive de votre groupe. Le navigateur ne synchronise pas votre notebook avec OneDrive. Ne pas se contenter de fermer l'onglet.
5. La routine doit être dans la cellule marquée « écrire la routine ». Le professeur peut récupérer cette cellule pour l'assemblage ; inutile d'installer Python ou de manipuler plusieurs modules pour le travail isolé.

Alternative : https://colab.research.google.com, ouvrir/importer le notebook téléchargé. Colab utilise le format .ipynb et exécute Python à distance ; un compte Google peut être demandé. https://research.google.com/colaboratory/faq.html.

Les 13 notebooks sont autonomes : données, formules, banc d'essai et graphiques sont inclus. Ils ne téléchargent aucun code distant. Le banc isolé conserve les diagnostics voisins prescrits ; le moteur collectif les recalcule au raccordement. Le groupe 13 utilise un climat de référence fourni afin de commencer sans attendre les autres groupes. L'extension pluie/océans du groupe 5 est une deuxième étape, avec ses relations fournies.

Un notebook représente une copie de travail du groupe. Pour éviter les versions concurrentes, désigner un élève qui tient la copie commune pendant la séance, et faire tourner les rôles. Indiquer membres et version avant dépôt.

Le notebook Classe_Explorer_le_monde.ipynb est collectif : choisir le monde, exécuter le moteur de référence fourni puis lire et télécharger le dossier de synthèse. Il ne remplace pas le travail des treize groupes. Il fournit un rapport HTML autonome avec six courbes, imprimable depuis le navigateur.
